# ADR 0003: separate proposals, execution and utility

Status: records the implemented baseline.

Frozen hand-authored expectations feed an independent structured oracle, never the
model. Gate decisions do not generate labels. Multiple authorized sequences may
satisfy a task. Report proposals, invalid outputs, executed violations and utility
separately: deny-all can avoid violations while failing every legitimate goal.
Development and held-out splits remain immutable. Twelve held-out cases and three
repetitions cannot establish statistical generality. Structured canary disclosure
is tested; unrestricted natural-language semantic leakage is not comprehensively
graded. Synthetic scripted traces are test fixtures, never live-model evidence.
